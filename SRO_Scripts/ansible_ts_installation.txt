The OS installation takes approximately 20 -40 minutes . It depends on the speed of the network.

IDRAC Security
While bringing up a new idrac server , the following security settings must be checked in order to harden the iDRAC .
1. Disable IPMI settings
Go to iDRAC Settings -> Network -> IPMI Settings -> Uncheck "Enable IPMI Over LAN"
2. Disable VLAN settings
Go to iDRAC Settings -> Network -> VLAN Settings -> Uncheck "Enable VLAN ID "
3. Setup SSL Encryption cipher suites
Go to iDRAC Settings -> Network -> Services -> Web Server -> SSL Encryption -> Choose "128 bit or higher" from the drop down
4. Enable TLS Support (Note: This option will be available in iDRAC which has firmware version > 2.40.40.40. Ignore if the step if the TLS option is unavailable)
Go to iDRAC Settings ->Network -> Services -> Web Server -> TLS Protocol -> Choose "TLS 1.2 only"
5. Enable SSH Settings
Go to iDRAC Settings -> Network -> Services -> SSH -> Check "Enabled"
Change Port Number to 22000
6. Disable Telnet
Go to iDRAC Settings -> Network -> Services -> Telnet -> UnCheck "Enabled"
7. Enable Remote Racadm
Go to iDRAC Settings -> Network -> Services -> Remote RACADM -> Check "Enabled"
8. Change SNMP Community Name
Go to iDRAC Settings -> Network -> Services -> SNMP Agent -> Check "Enabled"
Change the default SNMP Community Name "public" to the hostname like "080-100.exotel.in"
9. Disable Redfish Api Access
Go to iDRAC Settings -> Network -> Services -> Redfish -> UnCheck "Enabled"
10. Disable VNC Server
Go to iDRAC Settings -> Network -> Services -> VNC Server -> UnCheck "Enable VNC Server"
11. IP Filter iDRAC
Go to iDRAC Settings -> Network -> Advanced Settings -> Check "IP Range Enabled"
Enter the IP Range Address as 13.228.138.217
Enter the Subnet Mask as 255.255.255.254

Activation of ILL :
1. Enter username and Password
2. cd /etc/sysconfig/network-scripts/
3. vi ifcfg-em1 . (It depends whether em1 or em2 or em3 or em4 based on the ipconfig that you did during OS installation )
4. Check if IPADDR , Gateway ,DNS is Present . Confirm OnBoot=yes .
5. sudo service network restart
6. ping google.com should work
6.1 If ping does not work , run ifconfig and check if the ip that you gave is present. If not something is wrong in the ifcfg-em{1,2,3,4} file.
6.2 If ping doesn't work, may it be an ill issue. Check with NOC that the ILLs are connected to the server
6.3 If ping doesn't work, may be there is a mismatch in the settings ,like em1 is connected with an Airtel ILL but the ip you have entered in ifcfg-em1 might be a vodafone IP.
